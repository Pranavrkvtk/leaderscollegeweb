# Leaders College — Logistics Programme Website

A responsive React + Vite landing page based on the supplied Leaders College logistics poster.

## Run locally

1. Install Node.js (18+ recommended).
2. Extract this folder and open a terminal inside it.
3. Run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite.

## Build for deployment

```bash
npm run build
npm run preview
```

The production site is generated in `dist/`. It can be deployed to Vercel, Netlify, or any static hosting provider.

## Customisation notes

- Main page: `src/main.jsx`
- Styling and responsive layout: `src/styles.css`
- Supplied poster image: `src/logistics-poster.jpeg`
- Phone numbers, course text, address and programme topics are in `src/main.jsx`.
- The enquiry form opens WhatsApp with a pre-filled message; it does not store submissions in a database.
- Confirm all programme claims, certification details, admission dates and placement terms with the college before publishing.
